# 英検2級 完全攻略 Vocabulary & Idiom Master

英検2級合格のための、英単語・句動詞・熟語の学習ツールです。
単語帳・テスト・苦手の自動復習まで、ブラウザだけで使えます（インストール・ネット接続・有料サービス不要）。

## 開き方（いちばん簡単な順）

1. **ファイル1つで開く**：`dist/eiken2-vocab.html` をダブルクリック（スマホならファイルアプリから開く）。
   このファイルに単語データもすべて入っているので、コピーして別の端末に持っていっても使えます。
2. **フォルダごと開く**：`index.html` をダブルクリック。
3. **オフライン対応（アプリのように使う）**：フォルダで `npm start` を実行し、`http://localhost:8080` を開く。
   一度開けば、ネットがなくても使えます（スマホでは「ホーム画面に追加」もできます）。

学習記録は、開いたブラウザの中に自動保存されます（閉じても消えません）。
端末やブラウザごとに記録は別々なので、移したいときは「設定 → 学習記録のバックアップ」で書き出して、移した先で読み込んでください。

## 学習モード

| モード | 内容 |
|---|---|
| 1 単語帳 | 一覧・検索・分野別の絞り込み。タップすると意味・例文・類義語・使い分けを表示。英語のみ／日本語のみの表示切替 |
| 2 英語 → 日本語 | 単語を見て意味を思い出し、自分で○×をつける |
| 3 日本語 → 英語 | 意味を見て英語を入力（頭文字と文字数のヒント付き） |
| 4 4択テスト | 同じ品詞・同じ分野の紛らわしい選択肢から選ぶ（英→日／日→英） |
| 5 熟語集中 | 熟語・句動詞だけを、意味4択・前置詞選択・穴埋め・入力で集中練習 |
| 6 例文穴埋め | 例文の空欄に入る語を文脈から選ぶ |
| おすすめミックス | 4択・穴埋め・前置詞を混ぜ、苦手・復習期限の語を優先して出題 |

## 苦手管理と復習のしくみ

- 1語ごとに「学習回数・正解・間違い・連続正解・正答率・最終学習日」を記録
- 間違えた語は自動で **苦手** に登録され、優先的に出題。**3回連続正解で苦手から卒業**
- 正解するたびに次の復習までの間隔が延びる（10分 → 1日 → 3日 → 7日 → 14日 → 30日）。
  何度も正解した語は出にくく、間違えた語は出やすくなる
- 「苦手」タブで、苦手・復習期限・正答率が低い順・最近学習した語を確認・復習

## 収録データ

`node tools/validate.js` で最新の件数を確認できます。目標は単語2,000語以上・熟語500個以上。
品質を保つため、分野・品詞ごとのファイル（`data/`）に分けて少しずつ追加しています。

## 単語の追加・編集

1. `data/` のファイルを編集するか、新しいファイルを作る（形式は [docs/DATA_FORMAT.md](docs/DATA_FORMAT.md)）
2. `npm run check`（ファイル登録の同期と、重複・必須項目のチェック）
3. `node tools/build-single.js`（1ファイル版 `dist/eiken2-vocab.html` を作り直す）

## 構成

```
index.html            画面の骨組み
css/style.css         デザイン（ライト／ダーク対応）
js/                   アプリ本体（データとは分離）
  util.js store.js    共通処理／学習記録と復習スケジュール
  data.js quiz.js     データの索引・検索／出題と選択肢の作成
  speech.js app.js    発音／画面
data/                 単語データ（ファイルを足すだけで増やせる）
tools/                同期・検証・1ファイル版作成・ブラウザ動作確認
dist/eiken2-vocab.html  1ファイル版
sw.js                 オフライン用
```
