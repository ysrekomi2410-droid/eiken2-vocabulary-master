# 単語データ形式

データは `data/` 以下の `.js` ファイルに入っています。各ファイルは次の形です。

```js
EIKEN.add([
  { w: "reduce", ... },
  { w: "deal with", k: "ph", ... }
], "words-verbs-01");   // ← 第2引数はファイル名（出典管理用）
```

新しいファイルを作ったら **`index.html` の `<script>` と `sw.js` の `ASSETS` の両方に追加**してください
（`node tools/validate.js` が追加漏れを検出します）。

## フィールド一覧

| キー | 必須 | 内容 | 例 |
|---|---|---|---|
| `w` | ◯ | 見出し語（熟語は原形の形で） | `"reduce"`, `"result in"` |
| `k` |  | 種類 `w`=単語（省略時）/ `ph`=句動詞 / `id`=熟語・重要表現 | `"ph"` |
| `id` |  | 一意ID。省略時は `w`。同綴りの別語を入れる場合のみ指定 | `"present_adj"` |
| `ipa` | ◯ | 発音記号（IPA、強勢は `ˈ`）。熟語は省略可 | `"rɪˈdjuːs"` |
| `kana` |  | カタカナ発音の補助 | `"リデュース"` |
| `pos` | ◯ | 品詞（配列）。`v` 動詞 / `n` 名詞 / `adj` 形容詞 / `adv` 副詞 / `prep` 前置詞 / `conj` 接続詞 | `["v"]` |
| `ja` | ◯ | 日本語の意味（テストの選択肢にも使うので簡潔に） | `"〜を減らす、削減する"` |
| `key` |  | 英検2級で特に重要な意味・出題のされ方 | `"環境・経済の長文で頻出"` |
| `ex` | ◯ | 例文 `[英文, 和訳]` の配列。**対象語を `{}` で囲む**（穴埋め問題に使用） | `[["We must {reduce} waste.", "私たちは廃棄物を減らさなければならない。"]]` |
| `syn` |  | 類義語 | `["decrease", "cut"]` |
| `ant` |  | 反対語 | `["increase"]` |
| `rel` |  | 関連語（派生語など。「語 (品詞) 意味」の形） | `["reduction (n) 削減"]` |
| `col` |  | よく使われる組み合わせ（「英語 日本語」の形） | `["reduce costs 費用を削減する"]` |
| `lv` | ◯ | 重要度 `3`=最重要 / `2`=重要 / `1`=発展 | `3` |
| `tip` |  | 覚えるポイント・似た語との使い分け | |
| `pat` |  | 文法パターン（熟語で推奨） | `"result in A"` |
| `note` |  | 目的語の位置などの文法上の注意 | |
| `cat` |  | 分野タグ（複数可）: `env` 環境 / `sci` 科学・テクノロジー / `edu` 教育 / `soc` 社会・政治 / `eco` 経済 / `med` 医療・健康 / `life` 生活 / `human` 人間関係 | `["env","eco"]` |

### 例文の `{}` の付け方

- 活用形もそのまま囲む： `She {reduced} her costs.`
- 熟語で語が離れる場合は各部分を囲む： `We had to {put} the meeting {off}.`
- 1つの例文の中で `{}` は対象語だけに使う

### 品詞カテゴリと分野カテゴリ

- 「動詞・名詞・形容詞・副詞」は `pos` から、「熟語・句動詞」は `k` から自動で分類されます。
- 分野カテゴリは `cat` に書いたタグで分類されます（複数登録可）。

## ファイルの分け方

`data/<種類>-<品詞や分野>-<番号>.js` の形で、1ファイル 100〜150 項目程度に分けます。
大量に追加しても、読み込み後はメモリ上の配列で検索するため動作は重くなりません。
